# Підготовка до захисту лабораторної 1

## Як Java виконує програму

Файл .java містить текст програми. javac перевіряє синтаксис і типи та генерує байткод .class. Команда java завантажує класи у JVM і викликає public static void main(String[] args). public робить метод доступним; static дозволяє виклик без створення Main; void означає відсутність поверненого значення; args містить аргументи запуску. Назва public-класу збігається з назвою .java-файлу.

## Змінні й типи

Вісім примітивних типів: byte, short, int, long, float, double, char, boolean. Поля об’єкта належать конкретному екземпляру, static-поля спільні для класу, локальні змінні існують у межах виклику методу. Локальні змінні треба ініціалізувати перед читанням. int зберігає цілі числа від -2147483648 до 2147483647. double має похибку представлення десяткових дробів. Посилальні змінні містять посилання на об’єкт або null.

## Три режими формули

Для x=2, y=1 маємо xy=2, (x+y)^3=27, x²+y²=5, x-y=1. Результат 7.4. Другий режим читає int, але перед арифметикою параметри методу стають double, тому немає цілочисельного ділення 27/5=5. Третій режим (int) 7.4 дає 7; (int) -7.4 дає -7. Це відкидання дробової частини до нуля, а не округлення до найближчого цілого.

## Масиви та складність

Масив має фіксовану довжину й індекси 0..length-1. new double[n] заповнює елементи нулями. Алгоритм averages має два цикли: для кожного i підсумовує a[j]/(n-1) за j != i. Це O(n²) часу й O(n) додаткової пам’яті. Альтернатива B[i]=(S-A[i])/(n-1) потребує O(n), але віднімання великих близьких чисел може втрачати точність. Обрано наочний алгоритм для n<=200.

## Матриця як масив масивів

double[][] є масивом посилань на рядки double[]. У Java рядки теоретично можуть мати різні довжини; наш ввід створює саме квадратні матриці. У порівнянні рядків використано логічне «для всіх»: результат починається з 1 і стає 0 після будь-якого порушення нерівності. Рівність також є порушенням, бо умова строга.

## Текст і Unicode

String незмінний: перетворення створює новий рядок. StringBuilder накопичує результат без серії проміжних String. Регулярний вираз \p{L}+ знаходить слова з літер Unicode. Matcher дає межі слова, тому пунктуація та пробіли копіюються дослівно. codePoints відрізняє повні Unicode-коди від окремих char. Регістр враховується: «А» та «а» різні.

## Можливі питання

**Що робить main?**

Це точка входу. JVM викликає її після завантаження класу; послідовність операторів усередині визначає початковий сценарій програми.

**Чому main static?**

Для запуску не потрібно спочатку створювати об’єкт Main. Статичний метод викликається на рівні класу.

**Чим / відрізняється для int і double?**

Ділення int відкидає дробову частину. Якщо хоча б один операнд double, отримуємо дійсне ділення. У expression обидва параметри double.

**Що означає (int) result?**

Явне звуження типу. Дробова частина відкидається до нуля. Перед цим перевірено діапазон int.

**Навіщо hasNextLine?**

Він перевіряє наявність наступного рядка й дозволяє розпізнати EOF. nextLine повертає рядок. hasNextInt перевіряє цілий токен, nextInt читає його.

**Чи обов’язковий Scanner?**

Ні. Можна використати BufferedReader та розбір рядків. Scanner тут спрощує введення; у лабораторній 4 використано Reader.

**Як створити 10 цілих та матрицю 10x15?**

int[] a = new int[10]; double[][] b = new double[10][15];. Елементи отримають нульові значення.

**Чому X[i] спочатку 1?**

Це припущення істинності всіх нерівностей. Кожна невдала перевірка встановлює 0; назад у 1 у цьому рядку не повертаємо.

**Чому текстові роздільники не зникають?**

Код окремо копіює фрагменти між словами за межами Matcher.start/end.

**Для чого Math?**

Це стандартні математичні функції й константи: pow, sqrt, sin, cos, PI. Створювати об’єкт Math не потрібно.

**Яка складність задач?**

Вираз O(1), середні O(n²), матриці O(n²), перетворення тексту - лінійний перегляд знайдених слів і роздільників.

**Що буде з масивом довжини один?**

Програма відхилить його: після виключення одного елемента нічого не залишається для середнього.
