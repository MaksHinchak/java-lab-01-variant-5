# Лабораторна робота №1 • Варіант 5

Основи Java: вирази, масиви, матриці, текст

Автор: Гінчак Максим Богданович, 241-А.

## Завдання

- 1. Обчислити xy + ((x+y)^3/(x^2+y^2))·(x-y) у трьох режимах типів.
- 2. Для кожного i побудувати B[i] як середнє всіх A[j], де j != i; n <= 200.
- 3. Для двох квадратних матриць, n <= 15, отримати X[i]=1 лише тоді, коли кожен A[i][j] > B[i][j].
- 4. У кожному слові видалити всі попередні входження його останньої літери.

## Запуск в IntelliJ IDEA

Відкрийте **саме цю папку Lab01** через File → Open → New Window. Це самостійний проєкт, який не потребує сусідніх лабораторних. Оберіть JDK 17+ у File → Project Structure → Project SDK. На підготовленому Mac вже налаштовано `JBR-25-labs`.

У списку конфігурацій виберіть `Lab01_Main` і натисніть Run. Робоча тека - корінь цього проєкту.

## Запуск у терміналі

```sh
./run.sh
./test.sh
```

Скрипти беруть JDK із JAVA_HOME, установленої IntelliJ або PATH. Для Windows: створіть папку out, виконайте `javac -encoding UTF-8 --release 17 -d out src/*.java`, потім `java -cp out Main` (у PowerShell перелік файлів можна передати через `Get-ChildItem src -Filter *.java`).

## Демонстрація

1. Обери задачу 1; введи 2, 1, 2, 1. Побачиш 7.4, 7.4 і 7.
2. Обери задачу 2; n=3; A=[1,2,6]. Результат B=[4,3.5,1.5].
3. Обери задачу 3; n=2; A=[[3,5],[2,4]], B=[[1,4],[2,1]]. Результат X=[1,0].
4. Обери задачу 4; «мама, ананас!». Результат «мма, ананас!».
5. Покажи помилку x=y=0 і поясни, чому не можна ділити на нуль.

## Уточнення умови

- Для задачі 2 потрібне n>=2: середнє порожньої множини при n=1 не визначене.
- Слово в задачі 4 - послідовність літер; апостроф, дефіс, цифри та пунктуація є роздільниками. Регістр розрізняємо.
- Вхідні числа мають бути скінченними; обчислення виконуються з обмеженою точністю double.
